# LUNEVON LABS — Research Principles

## 1. Identify the object

A publication should identify the relevant build, device, Android version, dataset or experimental context whenever that information materially affects the result.

## 2. Separate measurement from interpretation

Measured values, observed behavior and engineering interpretation should not be presented as the same thing.

## 3. State limitations

Device-specific behavior, manufacturer restrictions, Android-version differences and experimental constraints should be disclosed when relevant.

## 4. Prefer reproducible evidence

Where practical, published conclusions should be supported by reproducible measurements, public technical references or clearly described inspection methods.

## 5. Avoid universal claims from narrow evidence

A result observed on one device, build or display technology is not automatically a universal Android result.

## 6. Protect proprietary material

Public research must not expose LUNEVON source code, credentials, signing material, internal infrastructure or commercial secrets.

## 7. Keep canonical publishing clear

Full bilingual publications live on **lunevon.com**. GitHub provides the engineering index, public records and supporting non-sensitive material.
