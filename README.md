## About

**LUNEVON LABS** is the public engineering and research space of **LUNEVON — Software & Technology**.

This repository indexes published investigations, technical experiments and engineering notes around Android, devices, diagnostics, connectivity and software design.

The canonical publication lives on **lunevon.com**. GitHub acts as a durable public index and engineering entry point.

## Research areas

LUNEVON LABS currently focuses on:

- **Android systems** — platform behavior, application architecture and runtime constraints;
- **Device intelligence** — hardware characteristics, metrics and diagnostics;
- **Battery & power** — battery behavior, display power and energy-related experiments;
- **Connectivity** — Wi-Fi, signal behavior and local network information;
- **Software engineering** — implementation tradeoffs, package size and validation;
- **Product engineering** — practical investigations that come directly from building LUNEVON software.

---

## Publication principles

Research published by LUNEVON LABS should be:

- based on a clearly identified observation, build or experiment;
- explicit about what was measured and what was inferred;
- clear about limitations and device-specific behavior;
- reproducible where practical;
- useful beyond a single product;
- free of private signing material, credentials and proprietary source code.

---

## Repository scope

This public repository may contain:

- publication indexes;
- public methodology summaries;
- non-sensitive measurements;
- diagrams and tables prepared for publication;
- public verification notes;
- links to canonical RU / EN articles.

It does **not** publish:

- LUNEVON product source code;
- signing material;
- credentials;
- private build systems;
- unreleased product internals;
- commercial secrets.
